# DOUR — Website Direction Prototype

A responsive, static front-end concept for DOUR, a Punjabi streetwear label aimed at US consumers.

## Run locally

No build step is required. Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## What's included
- Responsive homepage with mobile navigation
- Hero uses the sixth supplied reference image (`assets/hero-sixth-reference.jpg`)
- Editorial campaign sections, brand statement, design notes, palette and typography
- All supplied visual references copied into `assets/`

## Before launch
This is a visual proposal/prototype, not a production store. The supplied images are visual references and should be replaced with DOUR-owned/licensed campaign and product photography before launch. Product categories, prices, sizes, shipping/returns policies, checkout, payment integration, and the real brand contact details still need to be confirmed. The contact email is a placeholder.
